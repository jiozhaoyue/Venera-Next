# 下载删除入口

## Goal

在漫画详情页为已下载漫画提供删除全部下载 / 删除章节入口，并复用本地页的删除确认与章节选择逻辑；本地页现有入口保留。

## Requirements

1. 抽取本地删除确认与章节选择为可复用组件或函数，供 `LocalComicsPage` 与 `ComicPage` 共用，不复制删除逻辑。
2. `ComicPage` 在目标漫画存在本地记录时，提供明确的「管理下载」入口，包含：
   - 删除全部下载
   - 删除指定章节
   - 重新下载
3. 删除默认保留收藏与历史；只有用户显式勾选时才同时移除本地收藏与历史。
4. 删除全部调用 `LocalManager.deleteComic` 或 `batchDeleteComics`；删除章节调用 `deleteComicChapters`。
5. 删除后刷新详情页与章节下载状态；正在下载的任务不得被误删，需给出明确提示。
6. `LocalComicsPage` 现有入口与行为保持不变。

## Acceptance Criteria

- [ ] 已下载漫画详情页可见「管理下载」入口；未下载时不显示。
- [ ] 删除全部后本地记录和文件消失，收藏与历史默认保留。
- [ ] 删除选中章节后仅对应目录和记录被移除，其他章节可正常阅读。
- [ ] 下载进行中触发删除时给出明确提示，不执行误删。
- [ ] 本地页删除流程回归通过。
- [ ] 新增或更新 widget/单元测试。

## Notes

- 本地页已有单本删除、批量删除、删除章节（`local_comics_page.dart`），本 PR 只补详情页入口并抽取复用。
