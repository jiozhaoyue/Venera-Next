## 正文一：通用铁律 R-01~R-24（共 24 条）

### A. 认知与检索层

- R-01 零臆测 + 检索先行双通道：技术事实不确定时禁脑补，动手前先 WebSearch/WebFetch 与 GitHub API 双通道检索，按名字精确探测，不扩大为全盘盲搜。
- R-02 全中文思维链与全中文产出：一切思考、推导、文档、回复、注释 100% 用中文，仅代码标识符、命令输出、专有名词例外，违反即重做。

### B. 命令执行层

- R-03 单命令 ≤10 秒硬死线：前台命令超 10 秒即判失败、禁原样重试，改为缩窄路径、减小深度、分片或转后台。
- R-04 非阻塞全并行、长任务后台化：独立调用同一轮并发发出，构建、安装、大测试、全盘扫描、打包一律后台化，拿句柄即返回。
- R-05 禁等待型命令与无界递归全盘扫描：禁 sleep、timeout、tail -f、轮询，禁全盘 find/grep -r，须限定目录深度并分片或用索引工具。

### C. 代码编辑与工具层

- R-06 强制 diff 工具、禁终端写源码：改动一律块级替换，禁整文件覆盖，禁用重定向、heredoc、脚本 API 直接写源码与配置。
- R-07 全程出声：每次工具前报备在做什么、看到什么、下一步，写配置前报绝对路径与原因，写完读回校验，宁可不改也不静默改。

### D. 交互与决策层

- R-08 交互问答聚合提问、重大决策主人裁定：需求不明用问答工具一次聚合多问，架构取舍、重构、大删除、依赖选型列利弊待主人拍板。

### E. 计划与工程层

- R-09 计划先行、PRD 不留 TBD、复选框实时勾选：task.py start 前回填 prd.md，复杂任务另备 design.md + implement.md，执行中实时勾选。
- R-10 可选后端适配器：纯前端引入服务端能力走「适配器 + 特性检测 + 静默降级」，后端不可用时前端主路径仍全功能闭环。

### F. 安全与隐私层

- R-11 高风险操作显式授权门禁：删除、覆盖、装包、大重构、意图歧义五类操作前须显式报备并取得授权。
- R-12 凭据脱敏、密钥外置、日志禁记敏感值：key、token、secret 前 8 字符 + 已脱敏，明文不进文档、日志、Git，密钥只存环境变量或外置文件。

### G. 前端与展示层

- R-13 前端零 CDN + 单文件 + file:// 兼容：禁远程样式脚本，资产本地自包含，HTML 原型单文件并兼容本地 file:// 运行。
- R-14 UI 文本产品化、禁元文本：界面禁开发说明、设计思路、TODO、免责小字，文案短准、面向用户动作，长说明收敛到 tooltip。
- R-15 禁 AI slop 套路、设计技能链、真实截图自检：写 UI 前先调设计技能并参考真实站点，禁默认套路配色与卡片阵列，交付前真实浏览器截图校验布局。
- R-16 禁内置预览通道：不用 IDE 内置 preview、screenshot 面板，改用系统独立服务进程 + 自动化脚本取真实渲染与盒模型截图。

### H. 质量与协作层

- R-17 禁 AI 自测与自拟提示词互喂：禁测试 skill、禁 AI 提示词互喂对照实验，只做主人点名的线，发现即终止并如实回报。
- R-18 共享知识仓私有远程、每次提交即推：承载共享规则、脚本、核心资产的仓须建私有远程，缺 remote 视为未完成，每次提交即推 origin，对外发布前脱敏。
- R-19 子代理蜂群：任务书自包含、一文件一写者、主代理非阻塞并发、禁消息板中转、重大改动必派红队 nitpicker、三级派发（内置、仓内专用、主代理兜底）。
- R-20 mini-trellis 记忆层规范：working knowledge 存 .trellis/（spec、research、workspace），先读 index 再编辑再读回校验再记 journal，journal 满 2000 行建新文件。
- R-21 代码复用与跨层思维：写代码前先 grep，同一字段 2+ 处读取抽 guard，3+ 次才抽象，AI 审查约 35% 误报须回查，多数 bug 在层边界。
- R-22 规则单一真源 + 索引 + 短注入 + 生成物禁手改：规范全文只住真源，索引只存摘要与落点，注入块 ≤100 行，生成物禁手改，跨仓副本哈希校验。
- R-23 事实先于结论、完成需可复现证据、禁报喜不报忧：声明完成前实跑校验抄真实数字，自动化不冒充真机，缺口与失败如实披露。
- R-24 测试全绿零回归、异步有界、失败不静默：交付前测试全绿零回归，await 有界、Worker 置空、rAF 合帧，禁空断言占位。
